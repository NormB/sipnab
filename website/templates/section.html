{# Documentation search. The engine is Pagefind, which is not part of `zola build`: the "Index the site for search (Pagefind)" step in .github/workflows/pages.yml runs after it and writes /pagefind/ into the built site. That ordering is not a preference — `zola build` recreates its output directory from scratch, so an index written before it is deleted by it. Three properties this markup exists to hold: 1. NO INLINE SCRIPT. The production CSP is `script-src 'self'` with no 'unsafe-inline'; inline blocks are allowed only by sha256 hashes that ops/cloudflare/refresh_csp_hashes.py regenerates from the deployed HTML. The behavior lives in an external file instead, so there is no hash to keep in step and nothing to forget. 2. NO EXTERNAL ORIGIN. Pagefind's runtime, its wasm and its index chunks are all served from this site, so `script-src 'self'` and `connect-src 'self'` already permit them. A CDN would need the policy widened; nothing here does. 3. IT DEGRADES TO THE INDEX BELOW. The box ships `hidden` and only js/docs-search.js removes that, and only once the engine has loaded. With scripting off, or against a site built without the Pagefind step, the reader sees no search box at all — they see the "Reference" index further down this page, which is the same set of pages a search would have reached. An input that accepts text and can never answer is the failure being avoided. #}
