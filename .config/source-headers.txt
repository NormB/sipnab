# Which tracked files are SOURCE FILES, and the two statements each must carry.
#
# OpenSSF Gold `license_per_file` and `copyright_per_file`: every source file
# names the project license (as an SPDX expression) and the copyright holder
# in a comment near its top. This file is the ONE rule. Two consumers read it:
#
#   tests/source_file_headers_test.rs   the gate: every in-scope file carries
#                                       both lines within its first `window`
#   scripts/add-source-headers.py       the fixer: `--apply` inserts them
#
# A gate and its fixer must derive from one rule, so neither holds its own
# copy of the scope, the exclusions or the statements.
#
# Format: one directive per line, fields separated by runs of spaces. Blank
# lines and lines starting with `#` are ignored.
#
#   license    <SPDX expression>     the project license, verbatim
#   copyright  <holder>              written as `SPDX-FileCopyrightText: <holder>`
#   window     <N>                   both lines must sit in the first N lines
#   ext        <.ext> <open> [close] files whose name ends in .ext, and the
#                                    comment syntax the fixer writes them in
#   name       <basename> <open>     files with exactly this base name
#   prefix     <basename-prefix> <open>
#                                    files whose base name starts with this
#   shebang    <open>                any other file whose first line is `#!`
#   exclude    <path>                a tracked path that matches the scope but
#                                    is NOT ours to label (always commented)
#
# SCOPE RULE. A source file is a file a person writes as a program: code in
# a programming or build language (Rust, Python, shell, JavaScript and
# TypeScript, Go, SCSS, the site's Tera templates, Dockerfiles, Makefiles)
# and every executable script, whatever its name. OUT of scope, by kind:
#   - documentation (`.md`): prose about the code, not the code;
#   - configuration and data (`.toml`, `.yml`/`.yaml`, `.json`, `.jsonl`,
#     `.cfg.tmpl`, `.conf`, `.service`, `.tape`, `.yang`, `.txt`): declared
#     settings and inputs, not programs;
#   - test fixtures and captures (`.pcap`, `.pcapng`, `.trycmd`, `.snap`,
#     fuzz corpora): bytes a test feeds in or compares against, where an
#     added line would change what is being tested;
#   - generated artifacts committed to the repository (lock files,
#     `openapi.json`, `llms-full.txt`, rendered matrices): their generators
#     are what is maintained;
#   - fonts and images.
# Anything not matched below is out of scope; to widen the scope, add a
# directive here and run the fixer.
